Knights of the Void

A real-time, server-authoritative 10v10 team battle arena: click to move, fight for territory, capture objectives Arathi Basin-style. Built on REDGARDEN's own engine, named for real.

What this is

Two teams of ten, a living map with real capture nodes — walk a node uncontested and it starts flipping to your side, get spotted or take a hit mid-channel and you lose the progress, the same stakes as a real Arathi Basin flag. Territorial jungle creeps reward holding ground instead of just fighting for it. Click to move, Q/W/E for your kit. Desktop is the whole focus right now — no mobile build yet.

What's actually built (not a pitch, the real state)

  • VS0Bot-vs-bot matches — REDGARDEN's original card-RTS engine this all started from: the living grid, four starting cards, a working tech tree, a real win condition. Validated headless, end to end.
  • VS1Online play — matchmaking, connect-ticket accounts, validated with ten independent bots holding five concurrent matches under sustained load, zero crashes.
  • VS2Knights of the Void, live — a real click-to-move 10v10 arena with a growing hero roster (drawn from EINHORN_INDUSTRIAL's own multiverse lore — real Irish, Norse, and historical figures) and a genuine Arathi Basin-style capture system: exclusive presence, interruptible channels, stealth plays, territorial jungle creeps. Nodes are gated by real destructible towers, casters throw dodgeable skill-shot projectiles instead of instant hits, and a 27-item build-your-kit shop (with real actives like Blink Dagger) opens automatically as you approach it. Every match starts with a real click-to-pick hero draft, and hover-based targeting works like WoW macros. Not a pitch: a persistent bot pool is running real matches on this build right now, and a real external human connection has already been validated live.
  • NextRanked play — a rating system is designed (plain ELO), not yet built. More heroes queued, and a deeper jungle-camp ecosystem (full spec written, not yet built).

Play the current build right now

Every push to the main branch cross-compiles a real Windows client and uploads it as a GitHub Actions build artifact — no separate release process yet, but a genuine, current, downloadable build:

  1. Open the latest CI runs and pick the most recent green (successful) one on main.
  2. Scroll down to Artifacts and download red-garden-build. (GitHub requires a free account to download Actions artifacts, even on a public repo like this one — that's a GitHub platform limit, not something we're gating.)
  3. Unzip it, then unzip the RedGarden_Client_*.zip inside.
  4. Run PLAY.bat — it connects straight to our live persistent bot pool, no setup required.
