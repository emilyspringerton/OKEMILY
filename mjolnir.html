MJOLNIR

The Android app for Emily Prime — real-time push notifications, a live Apple audit-trail feed you can read offline, and in-app panels for the products this company actually ships.

What this is

MJOLNIR is a real Kotlin/Jetpack Compose Android app, built to be Emily Prime's phone. Firebase Cloud Messaging push notifications carry critical, high-priority, and routine alerts on three separate channels — critical alerts bypass Do Not Disturb. A synced, offline-readable copy of the Apples audit trail (the same append-only record every product in this ecosystem writes to) means you can read what actually happened without a live connection. WebView panels surface real product surfaces — status pages, dashboards — inside the app instead of a browser tab.

What's actually built (not a pitch, the real state)

  • Push notifications — real FCM integration, three real channel tiers, wired end-to-end to IDUNA's push-token registry and Emily Prime's own alerting.
  • Apple feed, offline-capable — a JGit-backed local cache of the APPLES archive, so the audit trail reads even without signal.
  • WebView product panels — in-app views onto real okemily.com and IDUNA surfaces, not a second copy of them.
  • Not yet true: there is no public build. CI is currently blocked on a real Firebase project secret that only a founder console visit can produce — not a code problem, an infrastructure setup step still outstanding. No Play Store listing, no APK to sideload today.
